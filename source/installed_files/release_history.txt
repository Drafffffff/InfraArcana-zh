= v23.0.0（2025年5月18日）

##############################
# Gameplay
##############################
# Terrain objects
- 一些地形物体现在会留下“铭文”，玩家可以通过撞上它们来研究。研究可获得 XP、找回遗忘的法术，并对携带物品产生“感觉”（例如判断药水是有益还是有害）。物品“感觉”不再随时间被动出现。
- 朦胧镜子不再回忆被遗忘的咒语，而是识别所有携带的物品。它们也比以前稀有得多。
- 如果玩家携带被诅咒的物品，敲锣很可能会获得“祝福”奖励（同时移除一项诅咒）。
- 魔法陷阱（“奇异形状”）会像机械陷阱一样重新隐藏起来，但陷阱不再生成于走廊中。
- 墓穴中出现的怪物种类现在会根据当前地城层数受到限制（此前，中后期怪物可能在游戏早期就从墓穴中出现）。

# Backgrounds (classes)
- 驱魔师不再可以无限期地存储高于最高等级的精神点，而是通过摧毁手稿、祭坛等获得热情点。热情可以用于施法，当没有足够的精神点可以施法时会自动使用。 “长寿”特质也用的是热情而不是精神。
- 由于上述变化，鞭打者特质“热情”已更名为“热情”。

# Traits
- 新增特质“贤者” - 这是“冥想”特质的升级，“专注”时也会以更高的技能等级施放法术，并且恢复专注状态的持续时间减少。
- 添加了“难以捉摸”的特征 - 盗贼的独特特征，使生物只记住你正常持续时间的一半。
- 快速恢复者每三回合而不是每两回合恢复 1 点生命值。
- 神射手特质现在也会提高最低伤害（但不会提高最高伤害）。

# Items
- 使用医疗包时，现在会显示一个菜单，您可以在其中选择要执行的治疗。还添加了一个像以前一样自动选择治疗的选项。
-医疗包新增“快速包扎”操作，可恢复一些生命值。
- 驱魔师圣徽现在可以使精神值超过上限（此前只能恢复精神值）。
- 新增“厚重外套”护甲，提供 2 点护甲，并使潜行和闪避降低 5%（这个物品很久以前就存在过，但当时的效果截然不同）。
- 删除了一些杆类型并添加了新的类型。此外，震耳欲聋的装置现在变成了一根杆。
- 将“抗火药水”和“绝缘药水”合并为“抗药水”，这也提供了抗毒能力并防止麻痹。 “抵抗”咒语已被移除。
-新增更多药水。
- 石棉套装现在可以抵御更多合理情况下的攻击（例如霉菌孢子）。
- 调整多种武器的平衡，尤其是让中型和重型武器相较匕首更有用。

# Spells
- 增加了“看见隐形”法术的持续时间。
- 瘟疫法术召唤的老鼠分散在整个区域（而不是聚集在施法者周围），并且该法术仅持续有限的时间。
-新增部分怪物可用的致盲法术（很久以前的游戏版本中也曾有此法术）。
- 移除“抗性”法术（现在改为药水，见上文）。

# Status effects
- 毒素现在可以叠加，也就是说，新毒素效果的持续时间会加到旧效果上（通常取新旧效果中较长的持续时间）。
- 毒药只能对生物造成最多 50% 生命值的伤害，但它也会降低近战伤害 25%，以及近战和闪避技能 10%。
- 中毒伤害现在触发得更少，但每次伤害更高。
- 当被缠住或卡住时，现在可以使用移动方向键近战攻击相邻的怪物（这与钉住状态一致，这已经是可能的）。

# Monsters
- 部分生物现在会“易燃”（例如霉菌和蠕虫群）。点燃后，它们会一直燃烧，也会点燃相邻的其他易燃生物。
- 霉菌不再造成直接伤害（只造成毒素伤害）。
- 致幻霉菌总是与普通霉菌一起开始。
- 霉菌“繁殖”时现在会以更加分散的图案出现。
- 冷蜘蛛网流星现在也会缠绕几圈。
- 虚空旅行者拦截玩家传送现在也结束了隐形和隐形。
- 更多怪物受到穿刺攻击时的伤害会降低（例如软泥怪和木乃伊）。
- 限制单个变形者可以变成的不同怪物类型的数量。
- 调整了多种怪物的平衡，包括属性、群体规模和特性等。
-新增更多怪物。

# Map generation
- 游戏后期洞穴中的废墟可能包含箱子、坟墓或祭坛。
- 地穴房间 (墓室) 和仪式房间 (带祭坛的房间) 也可以在游戏后期的洞穴中生成。
- 对地形物体在房间中生成的位置进行了一些改进，例如以前一些地形（如箱子或橱柜）永远不会在房间的角落生成。
- 一些房间现在会把地形扩展到房间之外（例如，蜘蛛房间可以在附近区域织出蛛网）。
- 改进了走廊生成：限制走廊最大长度、让走廊偶尔彼此连通，并在后期随机拓宽走廊，使其更像洞窟。
- 更改了一些令人讨厌的房间模板，或者创建了看起来像通向秘密门的死胡同走廊。

# Special maps
-部分特殊关卡新增开场提示弹窗。
- 使一些特殊关卡变得更加困难。

# Other gameplay changes
- 在游戏后期的洞穴关卡中，声音传播的距离增加了 50%。
- 怪物随时间生成的计时现在从进入新关卡后开始，而非按固定的全局间隔计算；这样可以避免玩家例如在楼梯旁等待来操纵计数器。
- 从游戏中完全删除“酸”作为伤害类型和概念。臃肿的尸体和尸丘吐口水现在造成零伤害并施加感染，奇怪的颜色造成纯粹的伤害。
- 重新设计并统一了近战和远程攻击的闪避惩罚计算方式。这通常不会明显改变游戏体验，但部分情况下命中率会受影响（例如，被困住现在也会降低对远程攻击的闪避率，而困惑不再造成闪避惩罚）。

# User interface
##############################
# Design
-撞击物体（门、尸体等）时新增闪烁动画。
- 消息淡出而不是立即被清除。
- 移除了许多会让游戏“暂停”（即显示“[空格]”提示）的情况；例如，发现隐藏门时不再暂停游戏。
- 当玩家死亡时，屏幕会变成红色。
- 火盆有微妙的闪烁效果，类似于玩家使用电灯笼时的效果。
- 查看怪物描述时，会显示当前的健康百分比。添加了禁用生命条的选项。

# Convenience / quality of life features
- 按 Tab 现在也会拆除相邻陷阱（优先进行近战攻击）。
-小地图界面新增图例，说明各种颜色的含义。
- 小地图现在会标记更多种类的地点和物体（例如墓穴、火盆等）。
- 数字键盘 0 也可用于打开和关闭小地图。
- 在“使用”菜单中，电灯笼固定使用快捷键“a”，医疗包固定使用“b”（驱魔师的圣徽使用“s”）。在“使用”菜单的第一页，这些物品始终置顶，其他物品不会占用这些快捷键。
-新增“b”快捷键，可在普通游戏模式中直接使用医疗包。
- 在大多数菜单和屏幕中，鼠标滚轮可用于上下滚动。
- 在任意位置双击都可切换全屏；此外还新增了启用或禁用此功能的选项。
- 现在，多个界面还支持使用 PgUp、PgDn、Home 和 End 滚动。

# Other user interface changes
-新增亮度设置。
- 游戏现在会隐藏鼠标指针。

# Fixes
##############################
- 修复了神射手专家会获得双重升级、神射手大师却完全无法升级的问题（该错误自 v20.0 起就存在）。
- 复活护符现在会先恢复所有生命值，再治愈所有创伤；这曾导致玩家生命值未能完全恢复。现已通过调整顺序修正。
- 拾取一堆手稿的驱魔师摧毁了整堆手稿，但只为一份手稿提供奖励。
- 驱魔师选择法术特质时才会显示可用精神值；角色信息界面不再显示这项信息（此前该界面显示的数值也可能有误）。
- 陷在泥中的持续时间原本有限，现在改为无限；玩家或生物必须主动挣脱。
-不再将“投掷炸药棒”加入消息记录。
- 修复了玩家控制传送时的计时问题（例如，施放传送法术后，到玩家开始选择传送位置之间，游戏时间原本仍会流逝）。现在可以立即控制传送位置。
- 还有更多错误修复...

##############################
# Modability, game data
##############################
- 字体图像不再硬编码在游戏中，游戏会搜索 gfx/fonts/ 目录下以 <width>x<height> 开头的 .png 文件（例如 "7x13_uushi.png"）。因此，只要把新的 .png 字体放进该目录即可添加字体。
- 现在可以按怪物最低地城层数的相对值指定 monsters.xml 中怪物群体规模所需的地城层数（格式为“+N 层”）。例如，若怪物的 min_dungeon_level 为 "4"，则 required_dungeon_level="+2" 的 group_size 条目会让该怪物从地城第 6 层起以该群体规模生成。

##############################
# Other
##############################
- 新增选项，可将 SDL 静态编译并链接到游戏二进制文件中（源代码包含在 Git 仓库中）。这样游玩或构建游戏都无需安装 SDL 依赖。默认情况下，Linux 会查找并使用系统安装的 SDL，Windows 则使用预编译版本。可通过 CMake 选项 "IA_BUILD_STATIC_SDL" 启用静态编译和链接（配置此模式时运行 cmake 并传入 -DIA_BUILD_STATIC_SDL=ON）。游戏的“官方”发行版均以静态链接 SDL 的方式构建，因此游玩这些版本无需安装 SDL 依赖。
- 游戏发行版现在基于 Debian Bullseye 和 gcc 10.2.1 构建；在 Linux 上运行游戏需要 glibc 2.31 或更新版本。
- 用户配置和选项现在通过 ini 文件处理（此前只是按特定顺序写入和读取文本文件中的各行）。
- 游戏目录中会放置 user_data.ini 文件，可在其中指定用户数据（高分记录、选项等）的存储目录。若留空，则使用默认位置。
- 启动时，游戏会检查多个位置是否可写（user_data.ini 所在位置、SDL_GetPrefPath 的返回位置，以及游戏目录本身），以寻找可写入用户数据的位置。

= v22.1.0（2023年9月24日）

##############################
# Gameplay
##############################
# Backgrounds (classes)
- 苦修者的“垂危”状态（低生命值奖励）现在会在受到伤害、生命值降至 6 点或以下时持续一段时间（此前只要生命值低于阈值就一直生效，恢复到阈值以上便立即结束）。此改动让玩家即使很快恢复到阈值以上，也能短暂利用该效果（例如施放“涤除污秽”法术，见下文）。
- 鞭打者也从一瓶活力药水开始。
- 计算分数时，鞭打者角色消耗的回合数会按较低数值计算（原数值的 55%）。鞭打者通常会消耗更多回合，尤其是每次行走都必须等待，因此此调整是为了让分数更可比。

# Traits
- “镀化”特质只有在施法会损失生命值时才会触发生命恢复（主要或仅适用于“剥除杂质”法术，见下文）。
- 增加了独特的鞭打特质“死亡纪念”，将垂死状态的阈值提高到8点生命值，并将效果持续时间增加50%。
- 将“死亡感”鞭打特质重命名为“热情”。
- 宝藏猎人将每层生成的物品增加 1 个，而不是 1-2 个。另请参阅下面生成的物品数量的一般变化。
- 改进了“生存主义者”特质：你不会感染，创伤数按半数向下取整计算（也就是说，计算战斗、生命值和恢复惩罚时创伤减半；创伤达到 6 处而非 3 处时行走速度才会降低；达到 10 处而非 5 处时才会死亡）。
- 治疗师不再是生存主义者的先决条件。

# Map generation
-新增特殊关卡
- 当“最终关卡”（无剧透）的怪物意识到玩家时，会打印一条消息（以减少对元知识的需求）。
- 在埃及关卡中，玩家进入距 Khephren 一定范围后，地图上的所有怪物都会察觉玩家。触发时会显示一条消息。

# Terrain objects
- 雾镜现在在激活后在小地图上呈灰色。
- 魔法搜索效果（“千里眼”能力）现在也能发现朦胧镜。

# Spells
-新增法术“涤除污秽”——苦修者背景的专属开局法术。此法术会降低生命值，使苦修者达到低生命值奖励的触发条件；若损失足够多的生命值，还会治愈中毒等部分状态效果。
-新增一种仅怪物可用的治疗其他生物的法术
- 嬗变法术现在是“阴暗的”（施展时暂时被遗忘）。
- 减少了光系法术在较高等级造成的失明效果的持续时间，并将法术消耗从2-4精神增加到3-5。
- “控制物体”法术的最大距离由 2/4/6 格调整为 3/4/5 格（基础/专家/大师级）。

# Items
- 重新设计了焚化炉，它现在被称为“Morphic Blaster”，是一种 Mi-Go 武器，其工作原理更像是电动枪。
- 下降药水现在可在所有关卡使用，直到“终点”（不剧透）；此前它只能在游戏结束前几层使用。
- 减轻了尖刺枪的重量。
-新增一种神器。

# Monsters
-部分怪物看到并察觉玩家后会等待一回合。每次怪物重新察觉玩家时只会触发一次。此设计旨在避免不公平的瞬间死亡，让玩家有机会先行动（例如邪教徒和白蜘蛛就会如此）。
- 白蜘蛛攻击有 20% c 几率麻痹，而不是 50%。
- 降低了幽灵的生命值（主要是为了让鞭打者玩家更有机会用“荆棘”法术对付它们）。
- 皮克曼从 10 级而不是 6 级生成，而且比较罕见。
- 皮克曼以 2-3 食尸鬼开始，而不是 4-5。
- 拜亚基现在从第 8 层起生成（此前为第 6 层），并且只有从第 10 层起才会成群出现。
- 木乃伊现在可以在意识到时说出一句话来提醒其他怪物。
- 当克拉彭·李少校“召唤他的古墓军团”时，召唤的怪物现在会等待一个回合，而不是立即行动。
- 触手簇现在可能随机出现在地图上（不再仅由法术副作用等因素生成），但出现几率较低
- 大幅调整了“猎犬”类怪物（火焰猎犬、能量猎犬）：新增种类、音效，并调整了许多属性。
- 对于会“繁殖”的怪物（即霉菌），若群体规模超过一定上限，就不会再生成新的怪物。
-新增更多怪物

# Misc balancing
- 看到“骇人”怪物获得的 XP 从 10 降至 8；看到“心智粉碎”怪物获得的 XP 从 20 降至 15（原因：现在怪物更多了）。
- 平均而言，游戏中期每层少生成一件物品 (10-19)，这是为了避免玩家以大量库存物品获胜，同时又不会让早期游戏变得更加困难，也不会降低游戏后期的探索回报。另请参阅上面的宝藏猎人更改。

# Other changes
- 在游戏结束摘要屏幕中，所有物品都在库存部分显示其识别名称。
- 角色界面（按“C”或“@”）的物品知识部分会列出游戏中所有可鉴定物品的真实名称，因此现在可以准确了解未鉴定的无害药剂可能具有什么效果。
- 删除了游戏总结屏幕的项目知识部分。
-新增提示弹窗，介绍状态效果、震慑等级、踢火盆和踢雕像等信息。
- “踉跄”消息现在更具体，会说明玩家踉跄的原因（“我的创伤让我踉跄不稳。”或“我被身上携带的重物压得踉跄。”）。
-负重超过 100% 时会显示警告。
-选择背景和特质时，“震慑”称为“精神震慑”，以免与某种震击伤害混淆（新玩家很可能会在游戏中首次遇到这个词）。
-怪物说明中新增踢击命中率信息。

# Fixes
##############################
- 修复了具有物理伤害抗性的生物可能被击入不可通行地形（例如墙壁）的问题。
- 修复了较长玩家操作（穿戴护甲或使用医疗包）会被中断的问题。此前，昏厥、燃烧、缠绕、受困等打断玩家的状态效果，无论施加给哪个生物都会中断玩家操作；当视野外的怪物陷入泥中时，这个问题尤其明显。
- 玩家不知道任何法术时，选择新特质期间查看已知法术信息会出现异常
- 游戏结束摘要的物品栏部分此前只显示单数物品名称（例如“投掷飞刀”）；现在会正确显示复数名称（例如“6 把投掷飞刀”）。
- 在角色界面和游戏结束摘要中显示已学法术的施放消耗时，遗漏了施放无领域法术（驱魔师专属法术）所消耗的精神震慑值。
- 当怪物打开门时，打开的门总是会在玩家记忆中更新，即使他们没有看到门被打开。
- 修复了处理门时重复显示声音消息的情况（“我听见门打开了。”“我看见一扇门正在打开。”）。
- 当盲人踢雕像时，永远不会打印声音信息（“我听到撞击声。”）。

-新增更多怪物
- 有些怪物有玩家可以闻到的气味
- 怪物不再因负面属性（燃烧等）或受到伤害而察觉玩家；它们会被直接攻击或攻击声惊动。因此现在可以向怪物投掷燃烧弹，并趁它燃烧时使用“云雾心智”逃走。

- 蠕虫群和噬脑蠕虫现在会失明、移动缓慢（此前为正常速度）、生命值大幅提高、令人不安（看见它们会造成震慑）；受到穿刺攻击（如手枪射击或匕首刺击）的伤害大幅降低，听觉范围也非常有限

- 从陷阱中产生的怪物现在在行动前稍等一下

- “自我觉察”特质的前置条件现在是“沉着冷静”，而非“善于观察”

- 移除了隐形净化棒
- 震波装置现在改为魔棒
- 震耳号角现在改为一种奇异装置

- 大锤不再将受害者击退
- 玩家传送后，如果怪物在新位置看不到玩家，它们就会变得不知道

- 坚毅药水不再治愈所有精神错乱症状（如恐惧症等），而只会治愈一种随机症状。

- 现在保证所有药水都能在你喝下时被识别
- 新增“法杖”物品类别：它们类似装置，但不会损坏或故障，而是在使用后进入冷却，冷却结束才能再次使用。

- 现在无法在黑暗中阅读卷轴

# Gameplay
##############################
- 现在角色升级时选择特质（与 v14 相同），而不是只在游戏开始时选择。新增了许多特质。每级选择一个特质；经验获取速度约为旧版本的一半，角色最高升至 10 级。

- 现在开始游戏时需要选择背景：“秘术师”（魔法）、“盗贼”（潜行）或“战争老兵”（战斗／枪械）。背景决定你的初始特质和物品；每种背景还有专属能力，而且有些特质要求特定背景。

- 现在发现怪物时可获得一半经验，击杀时获得另一半（未发现就击杀则获得全部经验）

- 现在可以通过听见或看见怪物来“察觉”它。这种“察觉”会持续数回合，并在怪物不在视野内时以感叹号（“!”）标记在地图上。这表示角色会更仔细地聆听脚步声等细微线索，并估测怪物可能前往的位置。此功能旨在帮助避免拐过墙角后立即被霰弹枪击杀等情况，让你有更多机会做出更好的决策。

- 地图上的对象不再通过弹出菜单（这种方式既慢又乏味）进行交互。你可以改用手册列出的标准键盘命令，例如用 [d] 拆除陷阱，或用 [q] 猛击物体。检查命令 [a] 现在仅用于搜索对象（例如寻找陷阱）。撞上物体时会尝试像平常一样使用它：打开箱子、饮用喷泉、走下楼梯，或阅读森林关卡墓碑上的碑文等。

- 猛击现在适用于更多情形。你可以猛击任意墙壁来尝试寻找暗门，也可以猛击尸体将其摧毁。猛击或踢击现在总会消耗一个回合，无论是否击中目标（“我踢了个空！”）。如果你试图踢击一个有隐形怪物的格子（可能是因为失明或怪物藏了起来），动作会像普通近战攻击一样处理（“我踢中了它”）。这修复了踢击隐形怪物时毫无效果的错误。

- 重新设计了奇怪的设备。现在，您不再需要启用它们来获得随机的偶然效果，而是激活它们以获得即时效果。它们可以被多次激活，尽管它们的状况可能会恶化，并且可能会发生故障或损坏。一些设备的效果也经过了重新设计。这些变化的结果是设备现在应该更有效并且使用起来更有趣。而且，它们现在更常见了，你甚至可以在第一个地下城关卡中找到它们。

- 理智错乱不再会在震慑达到 100% 或更高时立即上升；现在会先有三回合的警告信息，你可以趁机将震慑降到 100% 以下（例如在黑暗房间开灯、饮用坚韧药剂、下楼，或远离食尸鬼雕像）。

-新增近战攻击、施法、死亡和打开陵墓的音效——并加入更多环境音效
- 尝试施放可能耗尽精神值的固有法术时，游戏现在会要求确认
- 大大减少了弱化的持续时间
- 大幅缩短了通过喷泉、坟墓和法术感染疾病后的持续时间（只有通过感染获得的疾病才会持续很久）。
- 现在染病时会免疫感染（同时感染和染病属于重复且恼人的状态）
-新增“暗箭”手稿，类似“阿撒托斯之怒”，但只以一个怪物为目标，且基础施法耗费的精神值更少——选择“秘术师”背景可确保开局获得此法术
-新增法术“米戈催眠”，所有怪物都可使用（玩家除外）——所有米戈（犹格斯真菌）都会此法术；施放后有几率让你昏厥数回合
-新增一种仅怪物可用的法术，可使玩家燃烧数回合
- 将“千里眼手稿”改为药水，不再是不断地揭示你周围的怪物和地下城布局，而是立即揭示整个关卡的布局(包括物品，但不包括怪物)
-新增“侦测怪物”手稿，可在地图上用感叹号标记所有未见怪物，持续若干回合（被侦测到的怪物不会造成震慑）
-新增“元素抗性”手稿，赋予你暂时的火焰、寒冷和电击抗性
- 瘟疫手稿不再产生数十个怪物 - 现在是一个更合理的数字
- 生命值／精神值已满时，饮用生命／精神药水不再提高对应上限；现在它们可以暂时将当前生命值／精神值恢复到上限以上。
- 减少了垂直地图单元的数量
- 添加了两种常见怪物 (飞行息肉， Chthonians) 和一种独特怪物
-新增金色喷泉，保证会产生正面效果
- 听到声音不再会中断需要多个回合的动作（例如治疗）。
- 缩短了声音的传播范围，尤其是手枪开火等较响的声音。
-为各种怪物（如软泥类、灵体类）新增自然恐惧抗性和困惑抗性
- 击退不再造成混乱
-新增消息：怪物发现你并开始警戒时会通知你
- 更合理的规则，规定楼梯可以在哪里生成，以及玩家在哪里下降到下一个级别
- 按 [s] 时等待的轮数从 10 减少到 5
- 删除了“那应该做点什么吗？”的消息。阅读卷轴时没有明显效果
- “观察敏锐”特质不再直接让你发现隐藏门的线索（以黄色墙壁标示）；它现在只会提高发现门的几率，并允许你发现两格外的门（另一个“洞察”特质可将距离提高至三格）
- 木乃伊现在通常单独生成而不是成群生成
- 删除了“神话知识”，并删除了你在MTH达到一定水平时获得的法术
- 现在可以按 [d] 并选择方向来解除陷阱（地面和箱子上的陷阱都适用）
- 当电灯闪烁时，它现在只会将发光区域减少到 3x3 格，但它仍然可能发生故障，无法发出任何光，或者完全损坏
- 当受到阻碍时，现在有一个介于 100-125% 之间的区间，您可以以半速移动 - 在 125% 及以上时，您完全无法移动
-新增消息，提示你的精神值正在被吸取（例如被幽灵吸取）
- 尸检信息不再列出每种怪物的击杀数量，而是只列出击杀的唯一怪物以及怪物总数
- 受虐狂执念不再会在玩家受伤时恢复震慑值，而是只抵消受伤时通常会增加的震慑值（并将震慑下限提高至 35%）。

- 困惑现在会阻止施法
- 所有生物都有一定数量的精神。如果生物的灵魂耗尽，它就会死亡 (怪物有时会尝试施放可以杀死它的咒语，如果它“感到绝望”)。

- 新增“狂乱药水”——赋予“狂乱”属性：近战瞄准必定命中；无法施法或阅读；免疫困惑、睡眠、恐惧和虚弱；尝试朝任意方向移动时会走向最近的可见怪物；效果结束后会陷入虚弱。
-新增“精神药水”——恢复精神值
-新增“火焰抗性药水”
-新增“绝缘药水”——电击抗性
-新增“解毒药水”——治愈中毒

- 将“降临手稿”改为药水

- 修复了携带多个电灯笼导致您无法使用除顶部电灯笼之外的任何灯笼的错误

# Balancing
##############################
- 对AI进行了更改，使其行为不那么不理性，更具攻击性，特别是它不会像以前的版本那样在近战攻击之间来回跑动或传递攻击机会
- 让尚未察觉玩家的怪物每隔一个回合才行动一次（没有值得注意的事情时，它们不会全速移动）。这样潜行战术更有效，而且它们发现你后突然加速追来的样子也很酷。
- 通过观察来了解玩家对怪物来说算作一个动作 (给怪物一些反应时间，而不是立刻攻击)，尽管如果你事先提醒怪物，你仍然可能会立即被枪杀 (例如：制造噪音)
- 近战攻击不知情、昏厥、瘫痪或卡住的生物具有非常高的命中率加成 - 近战攻击失明、困惑、减速或燃烧的生物具有中等的命中率加成
- 麻痹时，可以防止额外的麻痹效果（具有此类攻击的生物很容易使你永久麻痹）
- 击退会造成混乱
- 虐待狂／受虐狂执念会使震慑值无法低于某个百分比，而不是提高震慑增长速度。
- 受到伤害时会受到少量震慑（有受虐倾向时除外）
- 焚化炉（凝固汽油弹发射器）现在使用弹匣（3 发），而非单发装填

> 瞄准人类大小的目标时，老鼠不会再挡住射击路线。
> 投射物可能会射偏目标，击中其后方的人。
> 可以将凝固汽油发射器瞄准地面。
